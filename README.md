# Графика в Web

Учебный проект о графике в веб-разработке: растровая и векторная графика, форматы изображений, Canvas.

## Ссылки

- [Сайт на GitHub Pages](https://228-reaper-822.github.io/graphics-in-web/)
- [Репозиторий на GitHub](https://github.com/228-ReAPeR-822/graphics-in-web)

## О проекте

Сайт рассказывает о том, какие бывают виды веб-графики, чем они отличаются, где применяются и когда что использовать. Материал разбит на отдельные страницы, чтобы можно было изучать тему последовательно — от общих принципов к конкретным форматам и технологиям.

## Страницы

- **[Главная](index.html)** — обзор темы, сравнение методов графики
- **[Растровая графика](raster.html)** — обзор форматов растровой графики
  - [JPEG](jpg.html) — сжатие с потерями
  - [PNG](png.html) — сжатие без потерь и прозрачность
  - [GIF](gif.html) — анимация и ограниченная палитра
  - [WebP](webp.html) — современный универсальный формат
- **[SVG](svg.html)** — векторная графика
- **[Canvas](canvas.html)** — динамическая графика с живым демо

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — кастомные стили поверх фреймворка
- **[Halfmoon](https://www.gethalfmoon.com)** — CSS-фреймворк
- **JavaScript** — Bootstrap Bundle (для offcanvas) + нативный Canvas
- **[Bootstrap 5](https://getbootstrap.com)** — JS-часть для интерактивных компонентов

## Как пользоваться сайтом

Перейдите по [ссылке](https://228-reaper-822.github.io/graphics-in-web/) или скачайте репозиторий, распакуйте архив и откройте `index.html` в браузере. Все страницы связаны между собой через навигацию.
