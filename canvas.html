Canvas

Canvas — это технология динамической графики, которая рисует изображение программно, в реальном времени. В отличие от SVG, где картинка описывается векторами, а от JPEG и PNG, где она хранится пикселями, Canvas не хранит изображение вообще. Каждый кадр рисуется заново с помощью JavaScript. Это даёт максимальную гибкость, но требует программирования.

История

Элемент <canvas> появился в 2004 году — его представила компания Apple для браузера Safari. Идея была простая: дать разработчикам возможность рисовать графику прямо в браузере с помощью скриптов, без сторонних плагинов вроде Flash.

Через год технологию подхватил консорциум WHATWG, а в 2014 году — после выхода HTML5 — Canvas стал официальным стандартом веба. С тех пор он поддерживается всеми современными браузерами без исключений.

В 2011 году появился WebGL — расширение Canvas для работы с 3D-графикой через GPU. Это вывело возможности браузерной графики на новый уровень: современные игры, редакторы, 3D-визуализации — всё это работает на Canvas и WebGL.

Особенности

Canvas — это не формат файла, а область для рисования. Внутри неё нет DOM-элементов: ни отдельных пикселей, ни линий, ни фигур. Есть только пиксели, которые скрипт перерисовывает каждый кадр. Это принципиальное отличие от SVG и других технологий.

Ключевые характеристики:

  • Программная отрисовка — изображение полностью создаётся кодом на JavaScript.
  • Растровый холст — внутри Canvas хранятся пиксели, а не векторы. При масштабировании картинка становится размытой.
  • 2D-контекст — рисование фигур, линий, текста, работа с изображениями, фильтрами и трансформациями.
  • WebGL (3D) — поддержка трёхмерной графики, использующей возможности видеокарты.
  • Анимация в реальном времени — Canvas перерисовывается десятки раз в секунду, что позволяет создавать плавные анимации и игры.
  • Не индексируется поисковиками — текст, нарисованный на холсте, невидим для роботов и скринридеров.

Главное преимущество Canvas — гибкость. Можно нарисовать что угодно и менять это на лету. Главный минус — сложность: без программирования Canvas бесполезен, а производительность зависит от оптимизации кода.

Применение

Canvas используется везде, где нужна динамическая или интерактивная графика. Основные сценарии:

  • Игры в браузере — Canvas и WebGL стали основой для веб-игр без плагинов.
  • Визуализации данных — графики, диаграммы, интерактивные карты, научные симуляции.
  • Редакторы графики — онлайн-фоторедакторы, инструменты для рисования, Figma, Canva.
  • Анимации и эффекты — частицы, фейерверки, интерактивные фоны.
  • Обработка изображений — фильтры, изменение размера, наложение эффектов прямо в браузере.
  • 3D-визуализации — через WebGL: трёхмерные модели, конфигураторы товаров, VR-сцены.

Каждый кадр Canvas полностью очищается и перерисовывается заново. Если остановить скрипт — на холсте останется последний кадр, который уже не меняется. В этом принципиальное отличие от SVG: там элементы существуют постоянно, а здесь есть только пиксели, которые обновляются по команде кода.

Canvas — мощный инструмент для динамической графики. Он не заменяет SVG или растровые форматы — у каждого своя задача. Canvas незаменим там, где нужна анимация в реальном времени, интерактивность и полный контроль над каждым пикселем. Для иконок и схем лучше SVG, для фотографий — JPEG и WebP, а для игр, визуализаций и редакторов — Canvas.
